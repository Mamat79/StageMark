# Consignes du dépôt de distribution StageMark

- Ce dépôt ne contient jamais le code source de l’application, le Worker de
  licence, une clé privée, un jeton, un secret Stripe/Cloudflare/Apple ou des
  données client.
- Le dépôt reste privé jusqu’à une décision explicite du propriétaire.
- Les installateurs Windows/macOS et leurs fichiers SHA-256 sont des assets de
  Release, pas des fichiers suivis par Git.
- Une Release stable doit provenir d’un tag vérifié du dépôt source privé et
  inclure une empreinte SHA-256 par installateur.
- Ne jamais annoncer un installateur macOS comme signé ou notarié sans preuve
  Apple réelle. Ne jamais annoncer la boutique comme active sans test Stripe.
- La banque de vidéoprojecteurs ne reçoit que des données et visuels dont le
  droit de redistribution est établi.

# StageMark 2026.6

Cette version Windows ajoute la prise en charge rétrocompatible des licences
V2 sans modifier les licences permanentes déjà distribuées.

- Les codes historiques `SMP1` et `SMF1` V1 restent portables, permanents et
  vérifiés hors ligne exactement comme dans StageMark 2026.5.
- Une licence V2 demande Internet lors de sa première activation et autorise
  trois installations par défaut.
- Après activation, le reçu signé et l'identité privée protégée par Windows
  permettent une validation entièrement locale, même hors ligne.
- **Désactiver cet ordinateur** libère une installation avant un changement de
  PC.
- Copier uniquement le code ou le fichier local ne copie pas l'activation V2.
- StageMark reste entièrement utilisable après 30 jours ; la licence supprime
  uniquement le rappel refermable.
- Le tarif reste un paiement unique de **49 € TTC** via Stripe.

Les DMG macOS publics restent en 2026.5. La boutique Stripe continue donc
d'émettre le format V1 compatible avec les deux systèmes jusqu'à la publication
et la validation d'une version macOS V2 signée.

La mise à jour Windows conserve les projets, calibrations, préférences et
licences existantes.

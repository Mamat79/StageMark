# StageMark 2026.9.3

Cette version adopte l’icône officielle StageMark fournie par SiLeMI/O dans
l’application, les raccourcis, les installeurs et la documentation.

- Fonctionnement autonome `.stagemark` conservé.
- Intégration StageFlow locale et LIVE réseau inchangée et facultative.
- Projection, calibration, contrôleur local et BLACKOUT inchangés.
- Installateurs Windows x64 et macOS Intel / Apple Silicon accompagnés de leur
  fichier SHA-256.
- Aucun code source, secret, clé privée ni donnée utilisateur dans cette
  distribution.

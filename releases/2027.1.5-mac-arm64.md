# StageMark 2027.1.5 — Mac Apple Silicon uniquement

Cette maintenance corrige les métadonnées de version du paquet Mac et exclut les fichiers de débogage `.map` de la distribution. Le comportement de l’application est conservé.

Deux fichiers sont proposés : le DMG Apple Silicon ARM64 et son fichier de contrôle SHA-256. Aucun nouveau paquet Windows ou Mac Intel n’est joint.

- Mac Apple Silicon : **2027.1.5**, minimum **macOS 12 déclaré**, sans matrice de tests sur les anciennes versions de macOS.
- Windows et Mac Intel : **2027.1.3 conservée**, disponible dans la [release versionnée 2027.1.3](https://github.com/Mamat79/StageMark/releases/tag/v2027.1.3). Ces anciens fichiers ne sont ni renommés ni nouvellement qualifiés. Intel 1.3 reste limité aux échanges V1 et refuse les projets V2.
- La release globale « Latest » reste sur Windows 2027.1.3. Utiliser les liens de cette release 1.5 pour télécharger le Mac Apple Silicon ; un ancien bouton ouvrant la page générique Latest peut mener à la version Windows précédente.

Les cinq bundles StageMark portent la version de construction 2027.1.5. Les métadonnées des frameworks tiers sont préservées. Le paquet ne contient aucune map propre ou tierce. Les notices FR/EN, le guide de suite, les trois clés publiques de licence et le catalogue sont conformes aux sources qualifiées.

La construction Mac compte **1 358 tests réussis et 27 ignorés**, sans échec : 1 268 Vitest et 90 Node. Ces résultats ne sont pas de nouveaux tests Windows. La vraie application du DMG monté en lecture seule a passé les contrôles natifs non visuels React, commandes CLI, conservation du projet et exports PDF/PNG. Le chargement du module Canvas ARM a été vérifié séparément sous Node ; il ne constitue pas un essai de ce module sous Electron.

Le paquet ne dispose pas d’une signature Developer ID ni d’une notarisation Apple. Des métadonnées de signature ad hoc ont été observées ; la vérification indépendante complète du bundle par codesign n’est pas établie. La fin du nettoyage est couverte par le producteur, sans inventaire indépendant des montages après détachement.

Aucune recette visuelle humaine complète, installation ou mise à niveau personnelle Mac, projection matérielle, téléphone, audio ou liaison LAN entre deux PC n’est revendiquée. Aucun Mac Intel 1.5 n’est qualifié. Le candidat Mac précédent au défaut de version reste non admissible ; ses résultats ne sont pas réattribués à ce paquet corrigé.

Pour les échanges : V1 reste le parcours par défaut. V2 utilise une nouvelle copie locale explicite, sans migration en place ; aucun échange V2 réseau/LIVE/AutoCAD n’est annoncé dans cette tranche. Conserver une copie V1 pour les applications anciennes et une sauvegarde avant toute mise à jour.
